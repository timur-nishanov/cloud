# Собери свой идеальный бандл

Тач-интерактив Yandex Cloud для стенда на конференции **Scale 2026**.
Гость решает бизнес-задачу, собирая связку (бандл) из сервисов платформы
данных. Концепт: сервис = деталь конструктора, бандл = собранный
механизм, правильная сборка = схема заработала и загорелась лампа.

## Запуск

Статика без зависимостей и сборки — открывается двойным кликом по
`index.html` (работает с `file://`) и деплоится на Vercel как есть.

Параметры URL:

| Параметр | Что делает |
|---|---|
| `?attract=blue` | синяя тема attract-экрана (режим «маяка» для стойки) |
| `?kiosk` | скрывает курсор (для тач-стойки) |

Сцена сверстана в макете 1920×1080 и масштабируется под окно, поэтому
на 4K-панели 3840×2160 всё увеличивается ровно ×2.

## Экраны

1. **Attract** — заголовок-узел из плит-слов, лента сервисов, CTA.
2. **Выбор режима** — «собрать самому» / «выбрать готовый бандл».
3. **Выбор задачи** — 10 задач для сборки, 6 для готовых бандлов.
4. **Сборка** — drag&drop и тап деталей в слоты, проверка, сигнал
   по цепочке. / **Готовые бандлы** — три схемы на выбор.
5. **Результат** — вердикт, эталонная связка, монета за конкурс.

## Структура

```
index.html, style.css, app.js   прототип целиком
CLAUDE.md                       бриф проекта и правила бренда (источник истины)
DESIGN-BRIEF.md                 бриф на визуальный полиш
assets/
  icons/      13 иконок сервисов игры
  logo/       логотипы Yandex Cloud
  details/    детали конструктора, отобранные под проект (+ перекрасы)
  pattern/    фоновый паттерн
fonts/        YS Display Black, YS Text Regular, CoFo Sans Semi-Mono (woff2)
  src/        исходные ttf/otf
library/      полные библиотеки брендбука — сырьё для новых композиций
reference/    прошлые прототипы (референс структуры, не стиля)
```

Перекрасы деталей в `assets/details/` помечены суффиксом: `--w` белый
корпус, `--b` бежевый, `--g` серо-голубой, `--k` чёрный.

## Контент

Тексты задач, связок и вердиктов — **заглушки** (`const DATA` в
`app.js`), заменяются после ревью архитекторов Яндекса. TODO-комментарии
в коде — открытые вопросы к заказчику.
