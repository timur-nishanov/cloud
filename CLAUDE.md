# Проект: «Собери свой идеальный бандл» — тач-интерактив Yandex Cloud / Scale 2026

## Задача
Собрать С НУЛЯ прототип игры для тач-стойки 55" (4K 3840×2160, ландшафт)
на конференции Yandex Scale. Гость решает бизнес-задачу, собирая связку
(бандл) из сервисов платформы данных. Два режима:
1. «Собрать самому» — drag-and-drop сервисов в слоты цепочки, кнопка
   «Проверить».
2. «Выбрать готовый бандл» — три готовых варианта, один эталонный
   (вердикты: «В точку / Сойдёт / Мимо»).
Успех = собранная схема «оживает»: по связям пробегает сигнал и загорается
лампочка #BFFF00.

## Исходники в проекте
- `bundle-game-prototype.html` — РЕФЕРЕНС, не основа. Предыдущая итерация:
  подсматривай механику (тап+драг, сигнал по цепочке, вердикты, структуру
  данных задач), но код пиши заново.
- Слоповый прототип от Яндекса (файл добавит человек) — источник СТРУКТУРЫ
  экранов и контента (тексты, список сервисов, счётчики). Его СТИЛЬ
  игнорировать полностью: градиенты, свечение, тёмный дженерик — всё мимо
  бренда.
- `refs/` — скрины брендбука, если человек положит. При спорных вопросах
  стиля сверяйся с ними.

## Стек
Максимально простой: статика без бэкенда. Один HTML-файл или index.html +
style.css + app.js. Без фреймворков, UI-китов, иконочных паков, CDN-шрифтов.
Должно открываться двойным кликом с флешки.

## ТИПОГРАФИКА
═══════════════════════════════════════════════════════════════════
- Заголовки и акценты: **YS Display Black**. Крупный кегль, плотный
  интерлиньяж (~0.98–1.05), это главный носитель характера.
- Наборный текст: **YS Text Regular**.
- Надписи в графике (маркировки на деталях, роли слотов, теги):
  **CoFo Sans Semi-Mono**, КАПСОМ, с лёгким трекингом (.05–.1em).
- Иерархию заголовков не менять, текст не красить в цвета вне палитры,
  выделения цветом — только отдельные слова в крупных заголовках (синим).

### Шрифты и логотип — взять с GitHub
Человек даст ссылку на репозиторий. Там МНОГО файлов начертаний — выбрать
самостоятельно ровно три и подключить через @font-face:
1. YS Display **Black** (не Bold, не Heavy — именно Black; если Black нет,
   взять самое жирное и оставить комментарий).
2. YS Text **Regular**.
3. CoFo Sans Semi-Mono **Regular**.
Предпочитать woff2 > woff > ttf/otf. Скопировать в `fonts/` проекта,
пути относительные. Проверить кириллицу.

Логотип Yandex Cloud из того же репо: SVG предпочтительно. Разместить:
- В шапке всех экранов (слева сверху, высота ~40–56px в макете 1920).
- На attract-экране — можно крупнее над заголовком.
На синем фоне — белая версия логотипа, на белом — чёрная (выбрать
подходящие файлы из репо; если версия одна — не перекрашивать хаком,
спросить человека).

## ВИЗУАЛЬНЫЙ ЯЗЫК: «конструктор» (сердце бренда)
═══════════════════════════════════════════════════════════════════
Всё интерактивное — «детали» инженерного конструктора:
- Флэт-плиты с прямыми кромками и ОДНИМ крупным скруглением/срезом угла,
  построение по модульной сетке, сочетание острых и скруглённых углов.
- Отверстия-кружки (одинакового размера в пределах фигуры).
- Слоты — пунктирные рамки с точками-отверстиями по углам, под слотом
  роль капсом (CoFo): «Поток», «Аналитика», «Дашборд»…
- Связи — прямые линии с «винтами» (кружками) на обоих концах.
- Декор: «шашка» (шахматный квадрат 2×2), капсулы-соединители.
- Уровни графики: attract = «ИТ-ландшафт» (россыпь множества мелких фигур),
  игровые экраны = крупные чистые детали 1–2 уровня, результат = 2 уровень
  + лампочка.

## МОУШН (из раздела 7.1 брендбука)
- Появление: резкий кат + 1–2 кадра инерции (CSS steps), БЕЗ fade/opacity.
- Стыковка детали в слот: короткий «клик» — snap + scale 1.05→1 за ~80ms.
- Сигнал по линиям: дискретные шаги ~12 fps (setInterval или steps()) —
  фирменный «лоу ФПС».
- Текст вердикта («В точку!») появляется ПОсловно, катами.
- Match cut между экранами приветствуется (выбранная задача «переезжает»
  в шапку сборки).
- Перемещения только по горизонтали/вертикали/45°; вращение — только
  вокруг осей отверстий, углы кратны 45°.
- ЗАПРЕЩЕНО: bounce, произвольные вращения, растяжение шейпов, физика
  частиц, параллакс, fade.

## КОНТЕКСТ ПОКАЗА (выставка: яркий свет, блики, люди стоят)
- Игровые экраны: белый фон, обводки 3–4px, никаких серых полутонов.
- Attract: синий #2A9FFF фон — виден через зал.
- Тач-цели ≥120px, текст крупнее веб-нормы в ~1.5 раза, мелкий текст
  не ниже ~16–18px в пересчёте на 1920.
- Hover не существует — только active/pressed. Курсор скрыть при ?kiosk.
- Критичные кнопки не выше ~65% высоты экрана (верх 55" панели неудобен).
- Drag-and-drop ОБЯЗАТЕЛЬНО дублировать тапом (тап по плитке = в первый
  свободный слот; тап по чипу в слоте = вернуть в палитру).

## ЛОГИКА
- Проверка сборки: по СОВПАДЕНИЮ НАБОРА сервисов с эталоном, порядок не
  учитывается. ОТКРЫТЫЙ ВОПРОС к Яндексу — может смениться на
  «набор + порядок», заложи проверку так, чтобы переключалась флагом.
- Контент (задачи, эталонные связки, тексты) — заглушки с пометкой TODO,
  структуру данных держать в одном месте (const DATA), заменится после
  текстов от Яндекса. Тексты-заглушки не «улучшать» самовольно.
- Ошибка: сигнал останавливается на первой лишней детали, лишние
  подсвечены, кнопка «Исправить» разблокирует сборку.

## БЭКЛОГ ПОСЛЕ БАЗОВОЙ СБОРКИ (по приоритету)
1. Idle-таймер: 60с без касаний → модал «Вы ещё здесь?», ещё 15с → сброс
   в attract с очисткой состояния.
2. Логирование в localStorage + экспорт JSON: session_id, ts, mode,
   task_id, события place/unplace/check, результат, длительность.
3. Attract-анимация «Клонирование»: россыпь периодически пересобирается.
4. Прогон на 3840×2160 и 1920×1080: цепочка из 4 слотов + лампа влезает,
   палитра из 13 плиток с иконками не наезжает на «Проверить».
5. Экран «монеты» для ветки готовых бандлов (награда за участие).

## ЧЕГО НЕ ДЕЛАТЬ
- Не добавлять градиенты/тени/скругления «для красоты» — флэт железный.
- Не тащить внешние библиотеки, CDN, Google Fonts, эмодзи, иконки не из
  Figma-файла.
- Не использовать #BFFF00 нигде, кроме лампы успеха.
- Не удалять TODO-комментарии — это открытые вопросы к заказчику.
- Не копировать стиль слопового прототипа (тёмные градиенты, свечение,
  цветные бейджи) — из него берётся только структура и контент.
