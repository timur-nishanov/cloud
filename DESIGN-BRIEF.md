# Дизайн-бриф: полиш прототипа «Собери свой идеальный бандл»

Тач-интерактив Yandex Cloud для стенда на конференции Scale 2026.
Гость решает бизнес-задачу, собирая связку (бандл) из сервисов платформы
данных. Концепт айдентики: **сервис = деталь конструктора, бандл =
собранный механизм, правильная сборка = схема заработала → загорается
лампа включённости #BFFF00**.

Это концепт-прототип — его будут дорабатывать после тебя, так что смелость
приветствуется. Задача: **сделать красиво, аккуратно и прикольно, строго
в айдентике**. Механику не трогаем, визуал — твоя территория.

## Чего от тебя ждут (в порядке важности)

1. **Чёткое следование айдентике.** Язык конструктора во всём: детали,
   винты, провода с терминалами, срезы углов. Не «примерно похоже»,
   а собрано по правилам брендбука (п. 2) из ассетов репо (п. 3).
2. **Моушн по принципам** (п. 2, блок «Моушн») — плавный, собранный,
   с характером. Можно добавлять свои моменты (стыковки, появления,
   реакции на тап), если они в этих принципах.
3. **Красиво собранные иллюстрации.** Композиции из деталей на карточках
   и экранах — как в `constructor-example/`: детали стыкуются осмысленно,
   провода идут от кромки к кромке, терминалы точно на стыках. Не
   раскиданные фигуры, а собранные узлы.
4. **Аккуратность.** Оптические отступы, сетка, выравнивания, единый
   визуальный вес элементов. Ничего случайного, ничего «на глаз».
5. **Прикольность.** Интерактив должен вызывать улыбку и желание
   потрогать. Микро-моменты, живые композиции, характер — welcome,
   пока это флэт и палитра бренда.

## 1. Границы

- **Механику и логику не менять** (`app.js`): навигация, drag&drop,
  тап-постановка, проверка сборки, сигнал, таймер, вердикты работают.
  Вёрстку, стили, координаты композиций внутри app.js менять можно.
- **Тексты и данные** (`const DATA`) — контент-заглушки заказчика,
  не редактировать. Служебные подписи-бейджи (типа «Drag & Drop»,
  «Быстрый режим», «Прототип») уже убраны — **не добавлять новых
  украшательных подписей**, текста на экранах ровно столько, сколько есть.
- **Стек**: статика без зависимостей — `index.html` + `style.css` +
  `app.js`. Без фреймворков, сборщиков, CDN и внешних запросов. Работает
  с file:// и деплоится на Vercel как есть.
- **Сцена**: макет 1920×1080, масштабируется через transform scale
  (#stage). Всё в координатах 1920×1080.
- **Ассеты — строго из репо.** Всё визуальное берётся из папок проекта
  (п. 3): детали, иконки, паттерн, логотипы, шрифты. Ничего не рисовать
  с нуля, не генерировать, не подключать извне. Если нужной детали нет
  в `assets/details/` — ищи в полных библиотеках (`base-details-*`,
  `connectors-elements/`, `thematic-details/`) и перекрашивай в палитру.
- **TODO-комментарии** в коде — открытые вопросы к заказчику, не удалять.

## 2. Железные правила бренда (нарушение = брак)

Полные правила — в `CLAUDE.md` в корне репо. Ключевое:

**Палитра (точные значения, не менять):**
- Основная: синий `#2A9FFF`, чёрный `#000000`, белый `#FFFFFF`,
  бежевый `#FCC67F` (акцент).
- Расширенная — ТОЛЬКО мелкие детали (винты, провода, шашки, статусы):
  серо-голубой `#B0BDD9`, светлый `#E7EBF4`, розовый `#FFB3ED`,
  фиолетовый `#B43ACE`, зелёный `#A5F898`.
- `#BFFF00` — сигнальный лайм, ТОЛЬКО состояние успеха: лампа
  включённости + подсветка цепочки в момент, когда схема заработала
  (класс `.live`). Больше нигде: ни в тексте, ни в декоре, ни в фонах.
- Пропорция на экране: синий/чёрный/белый ~85%, бежевый ~10%,
  расширенная ~5%.

**Запрещено наглухо:** градиенты, тени, glow, blur, полупрозрачности,
скругления «для красоты», эмодзи, иконки не из репо, Google Fonts / CDN.
Всё строго флэт.

**Типографика:**
- Заголовки: YS Display Black (weight 900), плотный интерлиньяж 0.98–1.05.
- Наборный текст: YS Text Regular.
- Маркировки на графике (роли слотов, теги, подписи): CoFo Sans Semi-Mono,
  капсом, трекинг сдержанный (.03–.05em, не разгонять).
- Шрифты уже подключены из `fonts/` через @font-face — не менять.

**Моушн:** плавный, единый ease `cubic-bezier(.22,.61,.36,1)` (переменная
`--e`). Без steps/«лоу-фпс», без fade/opacity-переходов, без морфинга,
без bounce и произвольных вращений. Базовые движения уже реализованы:
появление — вертикальный выезд (.cut), стыковка — snap 1.045→1, сигнал —
rAF по узлам цепочки, вердикт — пословный выезд из-под маски, успех —
цепочка «заливается» лаймом. Характер сохранить, тайминги и новые моменты
в этом же духе — можно.

**Визуальный язык «конструктор»:** всё интерактивное — детали: флэт-плиты
с одним крупным скруглением/срезом угла, винты-отверстия, слоты с
пунктиром, связи — провода с терминалами-креплениями (чёрный круг +
синяя точка), шашки как декор-мелочь. Эталон того, как детали собираются
в композиции — `constructor-example/`.

## 4. Зоны работы (по приоритету)

1. **Оптические отступы и сетка везде**: выравнивание блоков, равные
   поля, вертикальные ритмы на всех пяти экранах.
2. **Хиро (attract).** Слова-плиты заголовка: баланс кеглей, зазоры,
   связка заголовок → подпись → CTA. Паттерн по краям не должен спорить
   с лентой тегов. Если придумаешь, как красиво «собрать» плиты заголовка
   в единый узел по правилам конструктора — пробуй.
3. **Карточки задач.** Единый визуальный вес тематических иконок (они
   разной ширины и плотности), выравнивание типа/заголовка/описания
   между карточками.
4. **Карточки режимов.** Композиции деталей внутри — собрать интереснее
   и осмысленнее (слева «детали россыпью», справа «собранный механизм» —
   идею сохранить), по мотивам `constructor-example/`.
5. **Экран сборки.** Вертикальный баланс: задача → цепочка → палитра →
   кнопки. Роли под слотами, провода, лампа — выровнять оптически.
   Ритм палитры из 13 плиток.
6. **Готовые бандлы.** Схемы связок в карточках A/B/C: интервалы
   деталь-провод-деталь, буква-маркер, состояние selected — контрасты.
7. **Результат.** Вертикальная композиция: вердикт → зажжённая цепочка →
   плашка монеты → кнопки. Размер лампы относительно чипов.
8. **Вердикт-панель** (ошибка сборки): высота, отступы, блок
   «Правильная связка».
9. **Состояния кнопок**: disabled сейчас серый из расширенной палитры —
   можно решить лучше, оставаясь в палитре и без полупрозрачности.

## 5. Технические заметки (грабли, на которые уже наступали)

- Сигнал прорисовывает след: провод дорисовывается синхронно с точкой
  (`.link.drawing`), обводка детали загорается в момент прибытия
  (`.slot.lit` — лайм, `.slot.lit-bad` — розовый на лишней). Цвета следа
  и обводки должны совпадать, иначе теряется связь «точка → схема».
- Подложка-паттерн `.grid-bg` лежит на `z-index:-1`, поэтому белый фон
  задан на `#stage`, а не на `.inner`. Если покрасить фон `.inner` —
  подложка исчезнет.
- Центрирование через `transform: translateX(-50%)` конфликтует
  с анимацией появления `.cut` (она пишет transform). Центрировать
  absolute-элементы через `left:0;right:0;margin:auto;width:fit-content`.
- Шапка `.topbar` и кнопка «Назад» — absolute; не переводить в поток.
- `?attract=blue` — синяя тема attract для стойки, `?kiosk` — скрытие
  курсора. Обе должны продолжать работать.

## 6. Контекст показа

- Целевая поверхность: тач-стойка 55", 4K (сцена 1920×1080 → ×2).
  Тач-цели не уменьшать: плитки ≥88px, кнопки ≥72px высотой.
- Ближайшее демо: браузер на десктопе, мышь, деплой Vercel.
- Выставка = яркий свет: белые фоны, высокий контраст, никаких серых
  полутонов в тексте. Hover-состояний нет — только active/pressed.

## 7. Критерии приёмки

- Оба флоу проходятся мышкой на 1920×1080 без наездов и обрезок:
  сборка (успех / ошибка → «Исправить» / «Показать связку» / таймаут)
  и готовые бандлы (В точку / Сойдёт / Мимо / таймаут).
- Палитра — только значения из п. 2; лайм — только в состоянии успеха.
- Ни одного градиента/тени/полупрозрачности/fade в файлах.
- Шрифты — только три подключённых начертания.
- Все картинки — из репо, работает с file://, окно любого размера
  (letterbox чёрный).
- TODO-комментарии на месте, механика не изменилась.
